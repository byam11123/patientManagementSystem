# Patient Management System

A comprehensive patient management system built with modern technologies to streamline healthcare operations.

## 🚀 Features

- **Java & Spring Boot Backend**: Robust and scalable backend services
- **Microservices Architecture**: Containerized with Docker for easy deployment
- **PostgreSQL Databases**: Reliable and efficient data storage
- **Load Balancers & API Gateways**: Intelligent routing of requests
- **Event Driven Communication**: Using Apache Kafka for asynchronous processing
- **Real-time Communication**: Supporting both REST and gRPC protocols
- **Authentication & Security**: Secure APIs using bearer tokens
- **Integration Testing**: Comprehensive test coverage
- **AWS Deployment**: Infrastructure as code with LocalStack simulation

## 🛠️ Technologies Used

- **Backend**: Java, Spring Boot
- **Containerization**: Docker
- **Database**: PostgreSQL
- **Message Queue**: Apache Kafka
- **Communication Protocols**: REST, gRPC
- **Cloud**: AWS (with LocalStack for local development)
- **Infrastructure as Code**: Terraform/CloudFormation

## 🏗️ Architecture

This system implements a microservices architecture with:
- Service discovery and load balancing
- Event-driven communication patterns
- Secure authentication and authorization
- Scalable database solutions

## 🧪 Testing

Comprehensive integration tests ensure reliability and maintainability of the system.

## ☁️ Deployment

Deployed on AWS cloud infrastructure with infrastructure as code principles for reproducible deployments.

## 📋 Prerequisites

- Java 17+
- Docker & Docker Compose
- PostgreSQL
- Apache Kafka
- AWS CLI (for production deployment)
